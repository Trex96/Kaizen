# Kaizen

A sleek, automated anime downloader.

## Features

- **Automated Downloads** — Batch download entire anime series
- **Smart Detection** — Auto-detects episode count and quality options
- **Ad Blocking** — Automatically closes popup tabs
- **Progress Animation** — Real-time download status with styled output
- **Folder Management** — Creates organized directories per anime

## Installation

```bash
./install.sh
```

## Usage

```bash
./start.sh
```

Enter the anime episode URL when prompted, or press Enter to use defaults.

## Requirements

- Python 3.7+
- Chrome/Chromium browser
- macOS/Linux

## Dependencies

```
selenium
webdriver-manager
requests
tqdm
```

## Configuration

**Quality**: 360p, 720p, 1080p  
**Type**: Sub, Dub  
**Output**: `<anime-name>/Episode_<N>.mp4`
